## 优化历史

### 阶段0: Baseline (动态Loss Balancer之前)

| 配置 | Test MAE | 说明 |
|------|----------|------|
| Baseline | ~2.X | 未使用动态pos/neg loss balancer |

**关键发现**: 正负样本的不平衡导致训练不稳定

---

### 阶段1: 动态Pos/Neg Loss Balancer

| 配置 | Val MAE | Test MAE | 改进 |
|------|---------|----------|------|
| 阶段0 Baseline | ~2.X | ~2.X | - |
| +动态Loss Balancer | ~1.X | ~1.X | ▲~50% |

**关键机制**:
- `ema_pos_error`: 正样本误差的移动平均
- `ema_neg_error`: 负样本误差的移动平均
- 根据误差比例动态调整样本权重

**关键参数**:
```python
dynamic_pos_neg_loss:
  enabled: true
  ema_beta: 0.9      # 移动平均平滑系数
  alpha: 0.8         # 权重调整系数
  min_pos_ratio: 0.1
  max_pos_ratio: 0.9
```

---

### 阶段2: 非对称Density核 (当前)

| Kernel | sigma_left | sigma_right | Val MAE | Test MAE |
|--------|------------|-------------|---------|----------|
| 1E (baseline) | 30ms | 100ms | 0.81 | **0.48** |
| 1H | 25ms | 150ms | 0.81 | 待测试 |
| 1I | 15ms | 120ms | 0.82 | 待测试 |
| 1J | 20ms | 150ms | 0.97 | 待测试 |
| 1G | 20ms | 120ms | 1.01 | 待测试 |

**关键发现**:
- 左窄右宽的核效果更好
- sigma_left约20-30ms, sigma_right约100-150ms为最佳区间

**假设**: Cough事件的起始比结束更精确，应该用更窄的核

## 当前瓶颈分析

### 现状
- **最佳Test MAE**: ~0.48 (kernel 1E)
- **瓶颈**: Val MAE ~0.8，Test MAE ~0.48，差距较大

### 可能原因

1. **过拟合**
   - Val和Test之间有gap
   - 可能需要更多正则化

2. **密度核的限制**
   - 固定形状的核可能无法适应所有cough类型
   - 不同cough的持续时间差异很大

3. **模型容量**
   - TCN的感受野可能不够大
   - 或者模型结构不够flexible

4. **数据问题**
   - 标注噪声
   - 某些subjects的数据质量

## 进一步优化方向

### 方向A: 改进Density表示

1. **多尺度核组合**
   ```python
   density = 0.6 * narrow(sigma=20ms) + 0.4 * wide(sigma=100ms)
   ```

2. **可学习核参数**
   - 把sigma作为可学习参数
   - 或用小网络预测每帧的sigma

3. **事件自适应核**
   - 根据cough持续时间动态调整核宽度

### 方向B: 模型架构改进

1. **Attention机制**
   - Temporal Self-Attention
   - 让模型学习时间依赖关系

2. **多任务学习**
   - 同时预测density + cough事件边界
   - 辅助任务帮助学习

3. **残差连接优化**
   - Dense connections
   - 改善梯度流动

### 方向C: 训练策略

1. **两阶段训练**
   - 阶段1: 只优化MSE
   - 阶段2: 加入count loss

2. **Curriculum Learning**
   - 从简单样本开始

3. **数据增强**
   - 时间拉伸、音高变换
